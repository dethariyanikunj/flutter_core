## Version Management 💎

This project and its generated templates are configured to use **Flutter Version Management (FVM)**.

- **Automatic Setup**: The creation script (`create_project.sh`) will automatically check for FVM and the required Flutter version (`3.38.9`). If missing, it will offer to install them for you.
- **Manual Usage**:
  - Install FVM: `dart pub global activate fvm`
  - Install Flutter: `fvm install 3.38.9`
  - Run Project: `fvm flutter run`
